# Indian Festivals by Month

# Project Overview

This project is a semantic and accessible HTML-only web page that showcases important Indian festivals celebrated in each month of the year. It uses proper HTML5 elements like `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<figure>` to ensure a clear, meaningful, and accessible structure.

### Objective

To create a static webpage that:
- Educates users about major Indian festivals.
- Displays monthly festivals using structured HTML content.
- Organizes content by month using separate sections and images.
- Follows best practices for semantic HTML and accessibility.

### Features

- Semantic layout using HTML5 tags.
- Monthly timeline of festivals from January to December.
- Each month includes:
  - A brief description.
  - A relevant image using `<figure>` and `<figcaption>`.
